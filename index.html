Creating Your First Database in LibreOffice Base

Lab Handout & Guide
Before You Begin: Helpful Keyboard Shortcuts

Action Keyboard Shortcut
Move forward between fields or buttons Tab
Move backward between fields or buttons Shift + Tab
Open a dropdown menu Alt + Down Arrow
Confirm a dialog button (OK, Next, Finish) Enter
Cancel or close a dialog Escape

Part 1: Create the Database and Build the Animals Table

Step 1: Create and Save a New Database File

  1. Open LibreOffice from your Start Menu.
  2. Press Alt + F to open the File menu, press Right Arrow to expand New, and select Database (or press D on the main LibreOffice start screen).
  3. The Database Wizard dialog opens on the Select database step. Ensure the radio button Create a new database is selected.
  4. Press Alt + N (or Tab to Next and press Enter).
  5. On the Save and proceed step: Ensure Yes, register the database for me is selected.
  6. Press Tab once to move to the checkboxes and ensure Open the database for editing is checked (Spacebar toggles checkboxes).
  7. Press Alt + F (or Tab to Finish and press Enter).
  8. In the Save As dialog, type Animal_Rescue_Shelter in the File name box, select your class folder, and press Enter.
  9. The main LibreOffice Base window opens. Focus defaults to the Database pane on the left, where Tables is selected (Alt + A jumps directly to Tables at any time).

Step 2: Open Table Design View

  1. With Tables selected in the left pane, press Tab once to move into the Tasks pane.
  2. Use the Up Arrow or Down Arrow keys to highlight Create Table in Design View... and press Enter.
  3. The Table Design window opens. Your cursor is placed inside the first row under the Field Name column.

Step 3: Define Your Table Fields and Data Types

You will create five columns (fields) for your table. Type each field name, press Tab to move to Field Type, select the type, and press Down Arrow to move to the next row:

  • Row 1 (Unique ID): In Field Name, type AnimalID and press Tab. In Field Type, press Alt + Down Arrow, select Integer [INTEGER], and press Enter. Press Down Arrow to move to Row 2.
  • Row 2 (Animal Name): In Field Name, type AnimalName and press Tab. Leave Field Type set to Text [VARCHAR]. Press Down Arrow to move to Row 3.
  • Row 3 (Species): In Field Name, type Species and press Tab. Leave Field Type set to Text [VARCHAR]. Press Down Arrow to move to Row 4.
  • Row 4 (Age in Years): In Field Name, type Age and press Tab. In Field Type, press Alt + Down Arrow, select Integer [INTEGER], and press Enter. Press Down Arrow to move to Row 5.
  • Row 5 (Adoption Status): In Field Name, type Status and press Tab. Leave Field Type set to Text [VARCHAR]. (This field will store whether an animal is Available or Adopted.)

Step 4: Set the Primary Key and AutoValue

  1. Every database table needs a Primary Key to give each animal a unique ID number. Press Up Arrow four times until your cursor is back on Row 1 (AnimalID).
  2. Press Shift + Spacebar to select the entire row.
  3. Open the context menu by pressing Shift + F10 (or the Application/Menu key on your keyboard).
  4. Use Down Arrow to select Primary Key and press Enter.
  5. To make LibreOffice number each animal automatically, press F6 until focus moves into the Field Properties pane at the bottom of the window.
  6. Press Tab to locate the AutoValue dropdown, press Alt + Down Arrow, select Yes, and press Enter.

Step 5: Save and Close the Table Structure

  1. Press Ctrl + S to save the table.
  2. In the Save As dialog, type Animals as the Table Name and press Enter.
  3. Press Ctrl + W to close the Table Design window and return to the main database window.

Step 6: Enter Four Animal Records into Your Table

  1. In the main Base window, ensure Tables is selected (Alt + A). Press Tab twice to move into the Tables list at the bottom right, highlight Animals, and press Enter.
  2. The Table Data View grid opens. Notice the first column (AnimalID) reads AutoField—skip it, as LibreOffice fills it in automatically.
  3. Press Tab to move to AnimalName and enter your first record: Type Bella, press Tab, type Dog, press Tab, type 3, press Tab, type Available, and press Tab.
  4. Pressing Tab after the last column automatically saves Row 1 and moves your cursor to Row 2. Enter the second record: Press Tab past AutoField, type Oliver, press Tab, type Cat, press Tab, type 2, press Tab, type Adopted, and press Tab.
  5. Enter the third record in Row 3: Press Tab past AutoField, type Max, press Tab, type Dog, press Tab, type 5, press Tab, type Available, and press Tab.
  6. Enter the fourth record in Row 4: Press Tab past AutoField, type Luna, press Tab, type Rabbit, press Tab, type 1, press Tab, type Available, and press Tab.
  7. Press Ctrl + S to save your data, then press Ctrl + W to close the table view. Press Ctrl + S once more in the main Base window to save the entire .odb database file.

Part 2: Querying the Database for Available Animals

Now you will create a query to filter your shelter records so that it only shows animals whose Status is Available.

Step 1: Launch the Query Wizard

  1. In the main LibreOffice Base window, select Queries in the left Database pane by pressing Alt + Q (or use Up/Down Arrow until Queries is highlighted).
  2. Press Tab once to move into the Tasks pane.
  3. Highlight Use Wizard to Create Query... and press Enter. The Query Wizard opens on Step 1 (Field selection).

Step 2: Choose Which Fields to Display

  1. Focus starts in the Tables dropdown. Ensure Table: Animals is selected (use Alt + Down Arrow if you need to change it).
  2. Press Tab to move to the Available fields list.
  3. Highlight AnimalName, press Tab once to reach the > (Move Single) button, and press Enter.
  4. Repeat this process to move Species, Age, and Status into the Fields in the Query list.
  5. Press Alt + N (or Tab to Next and press Enter) to move to Step 2 (Sorting order).

Step 3: Sort Your Results Alphabetically by Name

  1. Focus starts in the Sort by dropdown. Press Alt + Down Arrow, select Animals.AnimalName, and press Enter.
  2. Press Tab once to confirm the Ascending radio button is selected (A to Z).
  3. Press Alt + N to move to Step 3 (Search conditions).

Step 4: Filter for Available Animals Only

This is where you tell the database to hide adopted animals and show only the ones ready for a home:

  • Ensure the radio button Match all of the following is selected.
  • Press Tab to move to the Fields dropdown, press Alt + Down Arrow, and select Animals.Status.
  • Press Tab to move to the Condition dropdown and leave it set to is equal to.
  • Press Tab to move to the Value box and type Available (make sure the spelling matches how you typed it in your table).
  • Press Alt + N repeatedly until you reach the final step (Overview).

Step 5: Name and Run Your Query

  1. On the Overview step, focus starts in the Name of the query box. Type Available_Animals_Query.
  2. Ensure the Display Query radio button is selected.
  3. Press Alt + F (or Tab to Finish and press Enter).
  4. A read-only results grid opens, listing only Bella, Luna, and Max (leaving out Oliver, who is marked Adopted). Use the Arrow keys to read through the rows and columns.
  5. Press Ctrl + W to close the query results, then press Ctrl + S in the main Base window to save your database file.

Quick Troubleshooting & Navigation Reminder

  • Switch to Tables: Alt + A
  • Switch to Queries: Alt + Q
  • Lost Focus in Table Design? Press F6 to cycle cleanly between the top grid (Field Name / Field Type), the bottom pane (Field Properties), and the toolbar.
  • Screen Reader Stops Announcing Grid Cells? Press Insert + Escape (in JAWS/Fusion) or NVDA + F5 (in NVDA) to refresh the virtual buffer, or press F2 to enter active cell-editing mode.
